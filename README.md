# PROJECT NEWMAD

Static investor showcase for **maponewmad.com** — Mapo Newmad, Mapo-daero 26, Seoul.

`index.html` is fully self-contained (no CDN, web fonts, or external assets) and serves
English, Korean, Chinese, and Japanese.

- Custom domain is declared in `CNAME`
- No build step; the repository root is the site
